# Mornye Play — кілька сервісів для онлайн-відтворення

## Що реалізовано
- ▶ обирає серед усіх ввімкнених розширень із підтримкою повного онлайн-потоку.
- Режим **Automatic** спочатку перевіряє джерело поточної композиції, далі — інші сумісні сервіси.
- Довге натискання ▶: вибір сервісу та якости відтворення. Режим автоматичного вибору — усталено.
- Для наступних пісень у черзі URL запитується безпосередньо перед відтворенням; якщо один сервіс не має запису, плеєр перевіряє решту.
- Короткі прев'ю, зашифровані потоки, HTTP без TLS та посилання з обов'язковими заголовками не приймаються як повний трек.
- Метадані звуку показують фактичний формат. AAC і MP3 не позначаються як FLAC.

## Доступні експериментальні розширення
- **Qobuz Online 1.2.29** — наявне розширення; потрібна дійсна сесія.
- **SoundCloud Online 1.0.15** — повні доступні прогресивні HTTPS-потоки; не короткі уривки та не HLS-only.
- **Jellyfin Online 1.1.2** — відтворення власної медіатеки через HTTPS із дійсним доступом до Jellyfin.

Розширення SoundCloud і Jellyfin збираються з відкритого Mornye-Extension у workflow `.github/workflows/multisource-online-extensions.yml`.

## Установлення
1. Установіть новий APK Mornye Play для ARM64 з успішної GitHub Actions-збірки.
2. Відкрийте **Settings → Extensions**, імпортуйте потрібні `.sflx`, увімкніть їх.
3. Для Jellyfin налаштуйте HTTPS-адресу власного сервера й облікові дані.
4. Натисніть ▶ або утримуйте ▶ для вибору **Automatic** / конкретного провайдера й якости.

## Обмеження
Spotify Web і Apple Music у стандартному реєстрі Mornye мають переважно каталожні/метадані функції, а не віддають повні аудіопотоки в цій схемі. Інші сервіси потребують окремої авторизованої інтеграції чи підтримки захищених форматів. Mornye Play не обходить DRM, підписок або авторизації. Beta потребує тестування на телефоні; оновлення APK поверх попередньої версії потребує незмінного ключа підпису.
